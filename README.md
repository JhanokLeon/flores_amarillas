# 🌻 Flores Amarillas Procedurales e Interactivas

Motor de animación procedural basado en HTML5 Canvas, CSS moderno y JavaScript puro (vanilla) para conmemorar el 21 de septiembre.

## ✨ Características
- **Tallos Procedurales:** Curvas cuadráticas de Bézier dinámicas con oscilación orgánica y crecimiento progresivo.
- **Pétalos Multicapa:** Disposición floral concéntrica doble renderizada mediante gradientes lineales y radiales de luminancia.
- **Partículas Ambientales:** Sistema de luciérnagas bioluminiscentes flotantes con efectos de brillo y desenfoque sobre lienzo.
- **Interfaz Glassmórfica:** Tarjeta responsiva moderna con filtros de desenfoque de fondo (*backdrop-filter*) e interacción para regenerar el jardín.

## 🚀 Despliegue en Vivo
Desplegable al instante mediante GitHub Pages directamente desde la rama `main`.
